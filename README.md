# BrightTV Data Analytics Initiative

This project supports BrightTV's goal of growing its subscriber base by using data analytics to uncover customer insights. The analysis focuses on customer segmentation, viewing behaviour, subscription trends, and churn to identify growth opportunities and provide data-driven recommendations that support the Customer Value Management (CVM) team's strategy .

Objectives: 
- *Subscription Growth:* Explore the factors that influence customer acquisition, retention, and churn.
- *Customer Segmentation:* Group customers and potential subscribers into meaningful segments using demographic information and viewing behaviour.
- *Behavioural Analysis:* Examine viewing habits to better understand customer preferences and improve content offerings.
- *Business Recommendations:* Provide data-driven recommendations that support CVM strategies and encourage long-term subscriber growth.
